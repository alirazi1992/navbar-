# سامانه مدیریت ناوبری

این پروژه یک داشبورد مدیریتی برای پایش عملیات بندری است که اکنون شامل یک سرویس پشتیبان ساده جهت مدیریت حساب‌های اصلی و کاربران زیرمجموعه است.

## اجرای پروژه

### پیش‌نیازها
- Node.js نسخه 18 یا جدیدتر
- npm

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای همزمان فرانت‌اند و بک‌اند
بک‌اند جدید روی پورت `4000` اجرا می‌شود و داده‌ها را در فایل `server/data/db.json` نگه‌داری می‌کند.

در دو ترمینال جداگانه دستورات زیر را اجرا کنید:

```bash
npm run server
```

```bash
npm run dev
```

فرانت‌اند به‌صورت پیش‌فرض به نشانی `http://localhost:4000/api` متصل می‌شود. برای استفاده از مسیر متفاوت، متغیر محیطی زیر را تنظیم کنید:

```bash
VITE_API_BASE="https://your-domain/api"
```

## ویژگی‌های کلیدی
- مدیریت حساب‌های اصلی (Primary Users) با امکان تعیین سقف اعتباری، تاریخ سررسید و وضعیت قفل سیستم.
- افزودن و ویرایش کاربران زیرمجموعه با نقش‌های تخصصی و نمایش نقش در کنار نام کاربر.
- قفل خودکار حساب‌های اصلی و تمام زیرمجموعه‌ها در صورت عبور از سقف اعتبار یا اتمام سررسید.
- کارت‌های آماری بر پایه داده‌های زنده‌ی بک‌اند برای پایش سریع وضعیت شعب.
- فیلتر وضعیت، جست‌وجوی هوشمند و نمایش جزئیات کامل هر شعبه در نمایی منسجم و راست‌به‌چپ.
- قالب‌بندی تاریخ و اعداد با استانداردهای فارسی (استاندارد `fa-IR`) برای تجربه بهتر کاربران فارسی‌زبان.

## ساختار سرویس پشتیبان
- `server/index.js`: سرور ساده Node.js با مسیریابی REST و پشتیبانی از CORS.
- `server/lib/data-store.js`: منطق داده، ارزیابی اعتبار و ذخیره‌سازی فایل.
- `server/data/db.json`: داده‌های پایدار (در اولین اجرا از بذر اولیه ساخته می‌شود).

پایگاه داده فایل‌محور برای نمونه‌سازی سریع طراحی شده است؛ می‌توانید آن را به سامانه‌های پایدارتر مانند PostgreSQL یا MongoDB گسترش دهید.
